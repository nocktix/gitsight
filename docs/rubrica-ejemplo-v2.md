# Rúbrica de ejemplo — Tarea 1: Calculadora de notas (versión 2)

Segunda versión de la rúbrica de ejemplo: cambia la descripción de C3, se endurece C4 y se
agrega C6. Sirve para probar las versiones de la rúbrica y su comparación.

| Criterio | Descripción |
|---|---|
| C1 - Uso de control de versiones | El historial de commits es frecuente, con mensajes que explican el cambio y sin bloques grandes de trabajo subidos de una sola vez. |
| C2 - Contribución individual | Cada integrante tiene commits propios y la distribución del trabajo coincide con lo declarado en Autoria.md. |
| C3 - Uso documentado de IA | La bitácora de prompts se construye durante el trabajo (varios commits a lo largo de los días), con fecha, herramienta y qué se hizo con la respuesta, y se corresponde con los archivos del repositorio. |
| C4 - Cumplimiento de plazos | No hay commits de trabajo posteriores a la fecha de entrega. |
| C5 - Calidad del código | Funciones claras, con validación de datos y pruebas que se ejecutan correctamente. |
| C6 - Declaración de autoría | Autoria.md nombra a todos los integrantes y cada uno aparece con commits en los archivos que declara. |
