# Rúbrica de ejemplo — Tarea 1: Calculadora de notas

Rúbrica ficticia para probar la herramienta con el repositorio de demostración
(`tarea-demo-equipo1`). Entrega: **martes 10 de marzo de 2026, 23:59**.

| Criterio | Descripción |
|---|---|
| C1 - Uso de control de versiones | El historial de commits es frecuente, con mensajes que explican el cambio y sin bloques grandes de trabajo subidos de una sola vez. |
| C2 - Contribución individual | Cada integrante tiene commits propios y la distribución del trabajo coincide con lo declarado en Autoria.md. |
| C3 - Uso documentado de IA | La bitácora de prompts registra el uso de IA generativa, con fecha, herramienta y qué se hizo con la respuesta, y se corresponde con los archivos del repositorio. |
| C4 - Cumplimiento de plazos | Los commits del trabajo están dentro de las fechas de inicio y de entrega de la tarea. |
| C5 - Calidad del código | Funciones claras, con validación de datos y pruebas que se ejecutan correctamente. |
